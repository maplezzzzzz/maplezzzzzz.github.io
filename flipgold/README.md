# 翻金镇 · 栗栗的金币庭院 — 世界旅行 4.0

在线：https://maplezzzzzz.github.io/flipgold/

## 美术

角色、金币、图标和大部分道具使用 Microsoft Fluent Emoji 的 3D PNG（MIT），界面、地面纹理和工具使用 Kenney 的 PNG（CC0）。素材已下载并打包成 4 张本地透明图集，游戏不依赖外部图片服务。Canvas 负责排版、绘制图片与动画。许可证原文、来源、下载哈希见 [assets](assets/CREDITS.md) 和 [sprites.json](assets/sprites.json)。

## 成长与旅程

- 庭院原有的铲子、伙伴、宝箱与钟楼成长继续保留。
- 第一片藏宝地后开放莓果果园；庭院钟楼修复后开放潮汐河湾。
- 后续区域需要前一区域完成 4 关并支付旅费：水晶矿谷、雪松山岭、风铃云岛、极光灯塔。
- 包含庭院在内共 7 个区域，每区 8 关，共 56 关。不同区域有独立场景、纪念币、收益倍率、天气效果与三页故事。
- 远征轮换五种目标：金币收集、闪光币、手动翻币、伙伴翻币、装备技能。免费入场，失败保留赚到的钱与装备。离开庭院打开菜单时暂停挑战；离线收益保留，但不计入挑战。
- 新发明：幸运耙、浇金壶、地脉钻、共鸣铃、星光提箱。拥有后可以免费切换，远征开始后固定装备。
- 阿绒增加共鸣、阿赤增加星砂、阿夜延长挑战。栗栗仍然每次只翻一枚币，通过训练和投喂提高频率。
- 胜利获得星砂，可持续精炼，提高手动、伙伴与离线收益。
- 抵达极光灯塔解锁无尽远征。其目标持续轮换，纪录不断增长。
- 全部 56 关完成后，可自愿开启下一轮旅行：重启区域关卡，保留财富、工具、伙伴、精炼、已解锁区域和故事；基础收益永久增加 25%。
- 无限循环复用已制作的区域与挑战，并非无限的新场景或新剧情。

## 存档

沿用浏览器存档键 flipgold-mobile-v2，旧金币、工具、伙伴、土地、故事不会重置。新增进度存于 play.world；首次迁移保留 before-world 备份。当前远征的目标、进度起点与剩余时间一并保存；后台离线收益不代替远征通关。

## 控制

移动端：轻触或滑过硬币；上下滑动地图和列表。
键盘：空格翻币、Shift+空格技能、F 投喂、Tab 选择、回车确认、Esc 返回。

素材导入和画面生成脚本位于 .github，素材仅从明确列出的官方来源下载。
